# Источники данных

Результаты исследования трёх сетей. Живой прогон 2026-10-17. API-ключи не нужны ни для одного источника.

## Lidl

- **Эндпоинт:** `https://www.lidl.bg/q/api/search` (JSON API каталога lidl.bg), постранично (`page_size`, `max_pages` в `config.ini`).
- **Формат:** `items[i].gridbox.data`. API отдаёт весь онлайн-ассортимент, поэтому адаптер оставляет только товары с реальной акцией: зачёркнутая старая цена, процент скидки или цена Lidl Plus. У товаров только для членов Lidl Plus нет `price.price` - цена Lidl Plus и обычная цена лежат в списке `lidlPlus`.
- **Соответствие полей:** id товара -> `product_ref`; цена -> `promo`; старая цена -> `regular`; цена Lidl Plus -> `loyalty` (program `lidl_plus`); даты акции берутся из данных товара.
- **Объём (2026-10-17):** 282 акционных предложения из 1061 позиции каталога; 192 текущих и 90 будущих; включая позиции только для Lidl Plus и многонедельные акции до 2026-11-08.
- **robots.txt:** используемые пути разрешены.
- **Риски:** недокументированный API; WAF myracloud (при частых запросах/без нормального User-Agent возможна блокировка - не обходим); API покрывает онлайн-ассортимент, позиции, существующие только в листовке, могут отсутствовать.

## Kaufland

- **Эндпоинт:** `https://www.kaufland.bg/aktualni-predlozheniya/oferti.html`.
- **Формат:** HTML (около 5 МБ) со скриптом `window.SSR['<uuid>'] = {...}`; данные в `props.offerData.cycles[].categories[].offers[]`. Циклы - текущая и следующая недели (пн-вс). Одно предложение может быть в нескольких категориях - берётся первая.
- **Соответствие полей:**
  - `offerId` -> `source_key`; `klNr` -> `product_ref`; `title` + `subtitle` -> `name`; `unit` -> `unit_text`; `dateFrom`/`dateTo` -> период; `listImage` -> `image_url`; `label` -> `offer_label`.
  - `price`/`formattedPrice` -> `promo`; `formattedOldPrice` -> `regular`; `loyaltyFormattedPrice` -> `loyalty` (`kaufland_card`, цена с Kaufland Card XTRA); `discount`/`loyaltyDiscount` -> `discount_pct`.
  - Скидки на бренд целиком (нет `title` и `subtitle`, около 38 шт.): `name` = `detailDescription` (например, «на всички артикули марка Хисар»), `description` = `detailTitle` («-20% отстъпка с KAUFLAND CARD XTRA»).
  - Акции «ВЗЕМИ 1+1 / 2+1 БЕЗПЛАТНО» (`detailTitle`): qty = a+b; показанная цена - итог за все qty штук, старая - обычная цена за все qty. Сохраняются `multibuy` (`min_qty`=qty, `kaufland_card`, если в тексте есть CARD) и `regular` = старая сумма / qty. На 2026-10-17: 71 такое предложение (1+1 без карты - 3 шт.; 1+1 с картой - 64 шт.; 2+1 с картой - 4 шт.).
  - Предложения без цены (описание акции текстом) сохраняются с пустым списком цен.
- **Объём:** около 2079 предложений в 2 недельных циклах; около 290 текущих с ценой Card XTRA.
- **robots.txt:** путь разрешён.
- **Риски:** разметка/структура SSR может измениться; тяжёлая страница (около 5 МБ) - запрашивается один раз за запуск.

## BILLA

- **Эндпоинт:** `https://ssbbilla.site/catalog/sedmichna-broshura` (текущая) и `https://ssbbilla.site/catalog/predstoyashta-broshura` (будущая). Это официальная текстовая версия брошюры для слабовидящих, на которую ссылается billa.bg.
- **Формат:** серверный HTML, плоский список `div.product`; название - свободный текст (`div.actualProduct`), цены - в колонках фиксированной ширины (старая цена + процент / акционная). Подпись «лв.» после процента - ошибка сайта, цены в EUR. Мультипаки несут цены только внутри текста. Строки без цен (заголовки, примечания) пропускаются.
- **Соответствие полей:** `product_ref` = хэш нормализованного названия; старая цена -> `regular`; акционная -> `promo`/`loyalty` по условию в тексте (`billa_card`, `billa_app`).
- **Объём:** 278 предложений; брошюра действует чт-ср. Страница будущей брошюры пуста, пока брошюра не опубликована (в субботу 2026-10-17 была пустой).
- **robots.txt:** `Disallow: /`. **Решение владельца проекта:** использовать этот источник, вежливо: 2 запроса за запуск, пауза, честный User-Agent с контактом; блокировки никогда не обходить. Если источник отвечает 403 - запуск сети падает, экспорт помечает сеть как stale.
- **Риски:** нет изображений и структурированных названий (только свободный текст); разметка может измениться; нарушение robots.txt - осознанный риск владельца.

## Юридические замечания

- Lidl и Kaufland: используемые пути разрешены robots.txt; данные публичные. Условия использования сайтов нужно проверить перед публичным распространением данных.
- BILLA: robots.txt запрещает обход; использование - решение владельца проекта (низкая нагрузка, 2 запроса за запуск, без обхода блокировок).
- User-Agent: `BGPromosBot/0.1 (+contact: <contact из config.ini>)`.

## Риски в целом

- Все три источника недокументированы: возможен дрейф разметки/структуры JSON. Защита: проверки полноты (`min_expected_offers`, `min_ratio` к медиане; считаются предложения, активные на дату запуска) - подозрительный запуск не перезаписывает данные; экспорт помечает сеть stale.
- WAF myracloud у Lidl; страница Kaufland около 5 МБ.
- Сырые ответы архивируются (`data/raw/`), что позволяет перепарсить после правки адаптера.

## Время обновления (наблюдения 2026-10-17)

- **Kaufland:** JSON предложений содержит срок `Expires` в 00:00 по Europe/Sofia (ежедневная смена) и перегенерируется в течение дня. Страница показывает текущую и следующую недели.
- **Lidl:** листовка следующей недели публикуется в четверг (startDate листовки - чт 15.10, предложения действуют с пн 19.10).
- **BILLA:** брошюра действует чт-ср; страница будущей брошюры в субботу пуста.
- Поэтому слоты по умолчанию - **06:30 / 12:30 / 18:30** по Софии.
- Реальные моменты изменений записываются на каждый запуск в `scrape_runs.content_hash` / `content_changed`. Посмотреть их:

```sql
SELECT chain, started_at, content_changed FROM scrape_runs WHERE content_changed = 1 ORDER BY id;
```

Выполнить, например: `sqlite3 data/bg_promos.sqlite3 "SELECT chain, started_at, content_changed FROM scrape_runs WHERE content_changed = 1 ORDER BY id;"`
